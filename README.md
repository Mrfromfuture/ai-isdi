# Saffron Table Restaurant Website

A complete responsive restaurant website built with semantic HTML, modern CSS, and lightweight JavaScript.

## Features

- Multi-section landing experience (hero, about, menu, gallery, reviews, reservation)
- Responsive navigation and layout for desktop/tablet/mobile
- Accessible markup (skip link, labels, focus states, ARIA attributes)
- SEO fundamentals (meta tags, Open Graph, canonical URL, structured data)
- Performance-focused setup (minimal dependencies, CSS preload, deferred JavaScript)
- Included `robots.txt` and `sitemap.xml`

## Run locally

Open `/home/runner/work/ai-isdi/ai-isdi/index.html` directly in your browser.
